## 代号速查

| 代号 | 类型 | 说明 |
|---|---|---|
| **厂商甲** | 手柄厂商 | 采用"网页驱动"方案的某国产手柄厂商（通过浏览器 HID 配置设备） |
| **厂商乙** | 手柄厂商 | 采用"力反馈扳机"方案的某国产手柄厂商（带原生配置下发协议） |
| **目标手柄α** | 手柄硬件 | 本项目最初做驱动兼容改造的目标手柄 |
| **手柄β** | 手柄硬件 | 厂商乙带自适应扳机的一款手柄 |
| **参考手柄** | 手柄硬件 | 某主流主机手柄，作为手感语义的对照基准 |
| **音频触觉引擎** | 软件 | 将系统音频实时转成触觉反馈的引擎（独立软件，非手柄固件） |

## 手感语义代号（跨厂商通用）

| 语义 | 含义 |
|---|---|
| 阻尼 (Race/Damper) | 扳机在某段行程内提供线性阻力 |
| 震动 (Vibration) | 扳机或握把提供周期性震动 |
| 射击 (Shot) | 扳机在某点提供突入式阻力/段落感 |
| 锁 (Lock) | 扳机行程被机械/模拟锁定 |
| 常规 (Normal) | 无特殊手感，自由行程 |

## 协议层代号

| 代号 | 含义 |
|---|---|
| 配置 blob | 手柄配置在传输层使用的连续字节缓冲区（不同厂商长度不同，例如厂商乙为 720 字节） |
| 位域打包器 | 厂商 UI 侧把"配置对象"按每字段 bit 数打包进 blob 的函数 |
| 报告帧 | 主机 → 手柄 的 HID 输出报告（含报告 ID、操作码、地址、数据、校验） |
| 设备门禁 | 厂商程序在枚举设备时校验 VID/PID/usagePage 的过滤逻辑 |

> 注意：以上代号在正文与代码中保持一致。任何涉及具体厂商实现的地方，一律以"厂商甲/乙"
> 指代，不出现可被反查到真名的字符串。
